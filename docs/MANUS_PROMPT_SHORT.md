Byg mig en moderne landing page for **TekUp.dk** med avancerede animationer.

**Om TekUp:**
TekUp er en dansk IT-virksomhed - "Din AI-partner i digital transformation"
- AI-løsninger, Software Development, Integrationer, Cloud Infrastructure
- Stats: 150K+ kode, 14+ projekter, 99.9% uptime, 2+ års erfaring

**Design:**
- Farver: Indigo (#6366f1) → Purple (#8b5cf6) → Pink gradients
- Animationer: Smooth scroll, fade-in, parallax, hover effects, stagger animations
- Styling: Modern, minimalistisk, card-based layouts, glassmorphism

**Sektioner:**

1. **Hero** - "Byg fremtiden med intelligent teknologi" + stats + 2 CTA buttons
2. **Services** (6 cards):
   - AI-løsninger (AI-assistenter, semantic search)
   - Integrationer (Gmail, Calendar, GitHub)
   - Software Development (Web/Mobile apps, APIs)
   - Data & Analytics (Knowledge bases, Dashboards)
   - Cloud Infrastructure (Hosting, Monitoring)
   - Sikkerhed & Compliance (OAuth2, GDPR)
3. **Integration Showcase** (3 highlights):
   - Gmail: Email management, AI-analysis, auto-reply (✅ Produktionsklar)
   - Google Calendar: Booking system, conflict detection (✅ Produktionsklar)
   - GitHub: Auto-sync, portfolio showcase (✅ Produktionsklar)
4. **Portfolio** - TekUpVault, TekUp-Billy, RenOS projekter med GitHub links
5. **Contact Form** - Klar til Gmail API integration
6. **Footer** - Links og social media

**Animation Requirements:**
- Scroll: Fade-in fra bottom, stagger grid items, parallax hero
- Hover: Cards lift+shadow, buttons scale+glow
- Micro: Button press, form focus glow, success animations
- Stats: Counter animations (0 → number)

**Tech:** Next.js 15, TypeScript, Tailwind CSS, Framer Motion
**Responsive:** Mobile-first, smooth animations også på mobile
**Tone:** Professionel dansk, human-centric, fokus på værdi

Resultat: Moderne, animeret landing page der bygger tillid og engagerer.
