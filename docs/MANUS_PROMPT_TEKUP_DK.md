# 🚀 Manus Prompt: TekUp.dk Modern Animation Website

## Prompt til Manus

Byg mig en moderne, professionel landing page for **TekUp.dk** med avancerede animationer og smooth transitions.

### 🎯 Hvad er TekUp?

TekUp er en dansk IT-virksomhed der hjælper virksomheder med digital transformation gennem:

- AI-løsninger og automation
- Software development (TypeScript, React, Next.js)
- Integrationer (Gmail, Google Calendar, GitHub)
- Cloud infrastructure og data analytics

**Tagline:** "Din AI-partner i digital transformation"

**Stats til at vise:**

- 150K+ linjer kode
- 14+ aktive projekter
- 99.9% uptime
- 2+ års erfaring

### 🎨 Design Requirements

**Farver:**

- Primary: Indigo (#6366f1) → Purple (#8b5cf6) → Pink gradients
- Dark mode friendly
- Modern, professionel look

**Animationer:**

- Smooth scroll animations
- Fade-in på scroll (scroll-triggered animations)
- Hover effects på alle interaktive elementer
- Gradient animations i baggrunden
- Parallax effects
- Micro-interactions på buttons og cards
- Stagger animations for grid items

**Styling:**

- Modern, minimalistisk design
- Generous whitespace
- Bold typography
- Card-based layouts
- Glassmorphism effects hvor relevant

### ✨ Animation Requirements

**Scroll Animations:**
